# iOS-Caffeinate v0.1.0 — Stable release notes

**Release channel:** GitHub stable (not a prerelease), explicitly requested by the project maintainer.

**Target:** iPad mini 2 A1489 / iOS 12.5.7 / Amethyst-Procursus **rootful** jailbreak. This is **not** a general-purpose stock iOS, rootless, or cross-jailbreak build.

**Package:** `com.ioscaffeinate.cli`, Debian version `0.1.0-1`, package architecture `iphoneos-arm` containing iOS ARM64 binaries with minimum deployment target iOS 12.

**Interfaces:** CLI `ios-caffeinate` (symlink alias `ic`) and foreground daemon `ios-caffeinated`.

**Signing:** The signed Debian package uses an explicitly reviewed Procursus `ldid` source revision and the narrowly scoped `amethyst-ios12-rootful` profile containing only `com.apple.private.security.no-container=true`. The distributable is tied to the exact successful main-branch CI build by source SHA and manifests. The package does not auto-start a daemon or enable launchd.

## What was observed on the reference iPad

The operator reported that individually signed CLI and daemon binaries executed on the reference device. Native IOKit power-assertion acquisition and release, 30-second automatic expiry, explicit STOP, and SIGTERM cleanup succeeded. Separate locked-screen authenticated LAN and Tailscale SSH probes each succeeded 24/24 times during an attended short test.

**Limits:** These tests were performed on *manually signed standalone binaries*, not on the installed stable .deb. The signed package's device installation, upgrade/removal, rollback and installed-path execution **have not been verified**. The package marks this transparently as `SIGNED-DEVICE-UNVERIFIED`, with `signature_verification=PENDING` until a suitable integrity verifier or device execution evidence is recorded. Testing also does not prove that power assertions caused persistence of connectivity, nor unattended 24/7 stability. Scheduled wake remains unverified.

## Before installing

Verify the SHA256 published next to the .deb and review `docs/P010-DEVICE-ACCEPTANCE.md` and `docs/P007-ROLLBACK.md`. Ensure `dpkg --print-architecture` reports `iphoneos-arm`, inspect package scripts, preserve a direct physical recovery method independent of SSH/Tailscale, and keep launchd disabled. Use only an attended, manually authorized installation. Do not interpret GitHub's non-prerelease label as evidence that outstanding acceptance or reliability gates have passed.
